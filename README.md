O objetivo é criar um sistema para a Dona Neide organizar as encomendas de bolos da confeitaria. O sistema permitirá cadastrar o nome e telefone do cliente, o sabor do bolo e os dados de entrega.

A ideia é facilitar o controle de pedidos, pagamentos e prazos de entrega. O sistema também irá gerar automaticamente uma taxa de urgência para pedidos feitos com menos de 24 horas de antecedência e mostrará os pedidos organizados pela data de entrega.

O sistema terá uma interface simples de usar, com letras maiores e núcleos em rosa bebê e branco.
